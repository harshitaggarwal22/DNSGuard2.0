DNS security guide

Core concepts behind DNS inspection and spoofing indicators.

⌁

What is DNS?

The Domain Name System translates human-readable names into records such as IP addresses and mail-server destinations.

⚑

DNS spoofing

An attacker attempts to make a client accept forged DNS information, potentially redirecting it to an unintended destination.

◇

DNSSEC

DNS Security Extensions use digital signatures. A validating resolver may set the AD flag when data has been authenticated.

⇄

Resolver comparison

Independent resolver answers can be compared for inconsistencies. Different answers may also be caused by CDNs or cache timing.

▣

Cache poisoning

False DNS records may be inserted into a resolver cache, causing clients to receive incorrect destinations.

✓

Prevention

Use trusted DNS resolvers, DNSSEC validation, secure network configurations and encrypted DNS where appropriate.
